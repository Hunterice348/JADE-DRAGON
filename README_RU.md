# JADE DRAGON — Китайский виртуальный инструмент

**Hunterice Records | Версия 1.0.0**

JADE DRAGON — MIDI-инструмент на JUCE с шестью синтезированными тембрами, вдохновлёнными традиционными китайскими инструментами: Guzheng, Erhu, Dizi, Pipa, Gong и Chinese Bells.

**Важно:** версия 1.0 генерирует звук алгоритмически. Это не библиотека настоящих акустических записей и не мультисэмплер.

## Возможности

- Форматы VST3 и Standalone.
- MIDI-вход и полифония до 16 голосов.
- Шесть тембров.
- ADSR-огибающая.
- Регулятор яркости гармоник.
- Встроенный ревербератор.
- Master Volume.
- Pitch Bend и Mod Wheel.
- Сохранение параметров проекта.
- Интерфейс в эстетике нефрита и старинного золота.

## Требования

- CMake 3.22 или новее.
- Компилятор C++17.
- Git.
- JUCE 8.0.6 (загружается CMake автоматически).
- Windows: Visual Studio 2022 с компонентом Desktop development with C++.
- macOS: Xcode Command Line Tools.
- Linux: GCC/Clang и системные зависимости JUCE.

## Сборка

Открой терминал в корневой папке проекта:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --target JADE_DRAGON_VST3 JADE_DRAGON_Standalone
```

Если названия целей отличаются в твоём генераторе CMake, выполни:

```bash
cmake --build build --target help
```

## Установка VST3

Скопируй собранный пакет VST3 в системную папку:

- Windows: `C:\Program Files\Common Files\VST3`
- macOS: `/Library/Audio/Plug-Ins/VST3`
- Linux: `~/.vst3`

Затем перезапусти DAW или выполни повторное сканирование плагинов.

## Управление

| Параметр | Назначение |
|---|---|
| Instrument | Выбор инструмента |
| Attack | Время атаки |
| Decay | Время спада |
| Sustain | Уровень удержания |
| Release | Время отпускания |
| Brightness | Яркость тембра |
| Reverb | Количество реверберации |
| Master | Общая громкость |
